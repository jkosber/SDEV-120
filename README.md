Coursework for **Ivy Tech SDEV 120**, completed Fall 2025 at Ivy Tech Kokomo as a late-start 8-week section (Nov 2 – Dec 21, 2025). SDEV 120 is the introductory logic and algorithm course in Ivy Tech's Software Development program; for me it counted as a foundational requirement toward the Cyber Security & Information Assurance Technical Certificate. The repository archives the weekly assignment submissions across all eight modules — pseudocode and flowcharts, the multi-module group project artifacts, the Python work introduced in modules 6–8, and a few class-meeting practice scripts.

## Catalog description

> Introduces the student to algorithms, algorithm development, and implementation. Students will utilize flowcharting / UML (Unified Modeling Language) as tools to design / document computer logic. Students will explore the organization and operation of a simple Von Neumann computer system. Included areas of study are base numbering systems, logical and relational operators. Students will implement simple scripts using structured programming techniques (e.g. sequence, conditional, repetition structures). Other concepts covered are order of precedence, data representation, logic gates, and scripting. Students will practice skills such as listening, team building, work ethic, communications, and documentation. Concepts will be demonstrated using UML, basic scripting, and simple programming code.

## Course learning objectives

Upon successful completion of SDEV 120 the student is expected to:

1. Demonstrate the usage of flowcharts, pseudocode, and UML diagrams to visualize / express algorithms and document system and software design.
2. Utilize logical and relational operators, control structures (sequence, selection, repetition), and modularity to design and implement algorithms as simple programs.
3. Apply a variety of strategies to test and debug simple programs.
4. Analyze and explain the behavior of simple programs that utilize variables, expressions, assignments, I/O, control structures, and functions.
5. Apply base-numbering-system techniques to convert numeric data between binary, decimal, and hexadecimal.
6. Illustrate the applications of hex and binary numbers within computing — numeric data (integer and real), character values (ASCII / Unicode), data storage, hardware (memory addresses, MAC addresses), networking (addressing / masking), color codes, images, sound, and video.
7. Identify the uses of various programming and scripting languages in computer systems.
8. Compare and contrast software / system development methodologies including SDLC, Iterative, and Prototyping.
9. Discuss the concepts and justifications for using secure programming and secure design techniques.
10. Describe the components of a simple Von Neumann computer architecture.
11. Explore the use of logic gates (AND, OR, NOT, NAND, NOR, XOR, XNOR) and combining them to create / simulate simple logic circuits.

## Module guide

- **Module 1 — Dev tools, simple program logic, pseudocode / flowchart, Von Neumann architecture.** Installed and experimented with the development tools (Lucidchart, Python IDLE, GitHub); first lab on understanding and developing simple program logic; first pseudocode statements / flowchart symbols exercise. Includes the introduction discussion on Von Neumann architecture components.
- **Module 2 — SDLC, modularization, variables + arithmetic.** Compared software development life cycles (SDLC, Iterative, Prototyping); designed modular programs; built flowcharts using variables, constants, and arithmetic. Discussion-board topic on security practices in programming.
- **Module 3 — Numbering systems, ASCII / Unicode, memory and logic gates.** Character values (ASCII / Unicode) worksheet; memory, network addresses, and logic gates worksheet; Number Systems quiz on binary / decimal / hexadecimal conversions. Group project introduced; separate History of Computer Architecture assignment.
- **Module 4 — Programming languages, testing & debugging, structures.** Programming / scripting language survey; four-part debugging exercise (DEBUG 01–04) practicing trace-the-bug workflow; flowcharting for compound structures; first group-project progress check-in.
- **Module 5 — Formulas, UML, structured programming, ethics.** Applying basic formulas; UML use-case diagram; principles of structured programming. Discussion-board topic on ethical obligations for IT professionals.
- **Module 6 — Python IDLE fundamentals, relational comparisons, AND / OR.** First IDLE Python script (and IDLE output capture); making decisions with relational comparison operators; AND / OR operator quiz; second group-project progress check-in.
- **Module 7 — Arrays and loops.** Arrays as memory-resident value collections; loop-based decision-making; Python `for` / `while` loops assignment with IDLE output capture.
- **Pseudocode/** — Three standalone Python exercises that reinforce decomposition: daily rent cost, breakfast steps as procedures, miles-per-gallon calculation.
- **Root `.py` files** — In-class practice from class meetings 2, 3, 4, and a `Pay Calc` exercise.
