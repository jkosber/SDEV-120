# SDEV-120 — Computing Logic (Python)

Coursework for **Ivy Tech SDEV 120: Computing Logic**, completed Fall 2025 at Ivy Tech Kokomo. Programming fundamentals and computational problem solving taught in Python — pseudocode, flowcharting, control flow, functions, basic data structures, file I/O, and testing/debugging discipline.

## Topics covered

- Computational thinking and problem decomposition
- Pseudocode and flowchart design
- Variables, data types, operators
- Control structures — `if` / `elif` / `else`
- Iteration — `for` and `while` loops
- Functions, parameters, return values
- Lists and basic data structures
- String manipulation
- Input / output and basic file handling
- Testing and debugging fundamentals
- Programming and scripting language survey (M04)
- UML use-case diagrams (M05)

## Tools and technologies

- Python (IDLE) — primary language
- Lucidchart — pseudocode and flowchart deliverables
- Excel — Module 3 character-value and memory exercises
- UML — Module 5 use-case diagrams

## Module guide

- **Module 1 — Setup and pseudocode foundations.** First Lucidchart flowchart, first Python program, GitHub account setup, pseudocode exercise (PDF/DOCX). Submission overview checklist confirms each part shipped.
- **Module 2 — Flowcharting and program planning.** Two exercises captured as both pseudocode (txt) and flowchart (PDF). Includes a discussion-board assignment on security-conscious programming practices.
- **Module 3 — Data representation.** Excel worksheets working through character values (ASCII / Unicode) and memory layout for primitive types.
- **Module 4 — Languages, debugging, and structures.** Survey assignment on programming/scripting language differences; a four-part debugging exercise (DEBUG 01–04) practicing trace-the-bug workflow; flowcharting practice for compound structures; a group-project progress check-in.
- **Module 5 — Planning and modeling.** Exercise-1 written plan, accompanying flowchart, and a UML use-case diagram.
- **Module 6 — IDLE practice.** Flowchart, IDLE Python script, and output screenshot — first end-to-end design-implement-verify cycle for an original script.
- **Module 7 — Loops capstone.** Python script using `for` and `while` loops, plus IDLE output capture confirming behavior.
- **Pseudocode/** — Three standalone Python exercises that reinforce decomposition: daily rent cost, breakfast steps as procedures, miles-per-gallon calculation.
- **Root `.py` files** — In-class practice from class meetings 2, 3, 4, and a `Pay Calc` exercise.
