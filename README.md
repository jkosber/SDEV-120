# SDEV-120 — Computing Logic

My Fall 2025 coursework at Ivy Tech Kokomo — late-start 8-week section (Nov 2 – Dec 21). Grade: A (Dean's List). SDEV 120 is the foundational logic and programming course — pseudocode, flowcharts, UML, then Python (IDLE) implementation in modules 6–8. It sits in the Software Development program but counts toward my Cyber Security & Information Assurance Technical Certificate. Repo holds weekly assignments across the modules — pseudocode and flowcharts, group-project artifacts, the Python work from M6–8, plus a few class-meeting practice scripts.

## Tools

- **Python (IDLE)** — implementation language for modules 6–8 (decisions, loops, arrays, functions, file I/O).

## Module walkthrough

- **Module 1 — Setup + first logic.** Installed and explored the dev tools (Lucidchart, Python IDLE, GitHub). First labs on simple program logic and pseudocode/flowchart symbols. Intro discussion on the Von Neumann computer.
- **Module 2 — SDLC, modularization, variables and arithmetic.** Compared SDLC, Iterative, and Prototyping. Built modular programs with flowcharts using variables, constants, and arithmetic. Discussion board: secure coding practices.
- **Module 3 — Numbering systems, ASCII/Unicode, memory and logic gates.** Worksheet on character values (ASCII / Unicode); separate worksheet on memory, network addresses, and logic gates; quiz on binary / decimal / hex conversions. Group project introduced; separate "History of Computer Architecture" assignment.
- **Module 4 — Languages, debugging, structures.** Survey of programming and scripting languages. Four-part debugging exercise (DEBUG 01–04) — trace the bug, fix it. Flowcharting for compound structures. First group-project check-in.
- **Module 5 — Formulas, UML, structured programming, ethics.** Applying basic formulas. First UML use-case diagram. Principles of structured programming. Discussion: ethical obligations for IT professionals.
- **Module 6 — Python IDLE, relational comparisons, AND/OR.** First IDLE Python script (output captured in a screenshot). Decisions with relational comparison operators. AND/OR operator quiz. Second group-project check.
- **Module 7 — Arrays and loops.** Arrays as memory-resident collections. Loop-based decision-making. Python `for` / `while` loops assignment with IDLE output capture.
- **Pseudocode/** — Three small Python exercises that drill problem decomposition: daily rent cost, making breakfast (steps as procedures), miles per gallon.
- **Root `.py` files** — In-class practice from class meetings 2, 3, 4, and the Pay Calc exercise.
